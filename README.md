# Git Flow Lab

A small front-end project used to practise Git Flow.

## Dark theme toggle

The header contains a **Toggle dark theme** button. Clicking it switches the
`data-theme` attribute on `<body>` between `light` and `dark`, and the styles in
`styles.css` change the page colours accordingly.

## Version

Current release: **v1.0.0**

## Project structure

- `index.html`: structure and content
- `styles.css`: presentation
- `script.js`: behaviour
